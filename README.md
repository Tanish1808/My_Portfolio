## ✨ Key Features

- **Responsive Single-Page Layout**: Smooth navigation across all sections with seamless mobile and desktop responsiveness down to 320px viewports.
- **Interactive Mock Terminal**: Built-in interactive CLI emulator with command history (↑/↓), tab auto-completion, XSS sanitization, and an embedded HTML5 Canvas Matrix digital rain animation.
- **2D Canvas Particle Network**: Dynamic background physics engine with mouse repulsion and proximity-based particle connections that adapt to dark/light themes.
- **Theme Switcher**: Dark mode (default) and Light mode with persistent state saved in `localStorage`.
- **Interactive Projects Dashboard**: Split-pane IDE showcase featuring smooth tab switching and direct GitHub repository links.
- **Certifications & Resume Modals**: In-browser PDF iframe viewing for verified credentials, and dynamic resume availability detection.
- **AJAX Contact Form**: Direct form submission powered by Web3Forms with automatic `mailto:` client fallback.

## 💻 How to Run Locally

Because this project is built entirely with vanilla web technologies, **no compilation or package installation is required**.

### Option 1: Direct File Open
Simply open `index.html` in any modern web browser.

### Option 2: Local HTTP Server (Recommended)
Running via a local HTTP server ensures smooth PDF iframe modal loading and CORS handling:

```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve .
```
Then visit **`http://localhost:8000`** in your browser.
